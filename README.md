# Chetan — Portfolio

A responsive developer portfolio built with React, TypeScript, and Vite. The visual style uses Outfit for display headings, Space Mono for interface text, and Caveat for handwritten accents.

## Getting started

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The page sections and initial project/toolbox content live in `src/App.tsx`. Update the contact link and project information there before publishing.
